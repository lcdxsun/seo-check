Privacy Policy

Last updated: September 2026 · SEO Health Check (browser extension)

Short version

SEO Health Check does not collect, store, transmit, or sell any personal data. All page analysis runs locally inside your browser.

What stays on your device

  • All SEO analysis results (scores, checks, keywords, performance metrics) are computed in the extension and never leave your browser.
  • Language preference, PRO license status and analysis history are stored only in your browser's local extension storage (chrome.storage / IndexedDB). They are not sent to us.

The only network requests the extension can make

  • robots.txt / sitemap.xml of the site you are analyzing — fetched to determine crawl permissions, only when you run an audit on that page.
  • Lemon Squeezy license API (api.lemonsqueezy.com) — called only when you voluntarily paste a PRO license key to activate or deactivate it. The key is verified by Lemon Squeezy; we operate no backend server.
  • AI providers you configure yourself (optional) — if you enable AI advice with the cloud engine, audit data of the current page is sent directly from your browser to the provider you chose (e.g. GLM, OpenAI, DeepSeek) using your own API key. This data does not pass through us and we never see it. The on-device AI engine works fully offline.

No tracking, no accounts, no analytics

The extension contains no analytics SDKs, no ads, no account system, and does not record browsing history.
